💾 DriverBackup首頁使用方式運作原理建置

使用方式

需要 Windows 10 或 11，並以系統管理員身分執行。

匯出驅動

  1. 啟動程式（會要求系統管理員權限）。
  2. 選擇備份目的資料夾。
  3. 按「Start Export」。
  4. 完成後資料夾內會有匯出的驅動與 sys.session。

匯入驅動

  1. 啟動程式（會要求系統管理員權限）。
  2. 選擇單一 .inf 檔，或含多個 .inf 的資料夾。
  3. 按「Start Import」。
  4. 若已有同名驅動，程式會詢問是否覆寫。
沒有系統管理員權限時，匯出與匯入可能失敗。
