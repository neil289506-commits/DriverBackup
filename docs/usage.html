Usage

使用方式

需要 Windows 10 或 11,並以系統管理員身分執行。

匯出驅動

啟動程式

會要求系統管理員權限。

選擇目的資料夾

選擇備份目的資料夾。

按 Start Export

開始匯出。

完成

資料夾內會有匯出的驅動與 sys.session。

匯入驅動

啟動程式

會要求系統管理員權限。

選擇來源

選擇單一 .inf 檔,或含多個 .inf 的資料夾。

按 Start Import

開始匯入。

處理重複

若已有同名驅動,程式會詢問是否覆寫。

沒有系統管理員權限時,匯出與匯入可能失敗。
