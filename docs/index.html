DriverBackup

Windows 桌面工具，匯出與匯入第三方裝置驅動程式。 使用系統內建的 pnputil.exe 備份驅動程式存放區，並從 .inf 還原。 以 Rust 與 egui 製作。

使用方式 運作原理 ⬇ 下載 driver_backup.exe GitHub Releases

匯出全部第三方驅動

一次匯出到你選的資料夾。

sys.session 紀錄

記錄 Windows 版本、匯出時間、驅動總數與完整清單。

單檔或整個資料夾匯入

可選單一 .inf，或遞迴掃描整個資料夾。

重複偵測

匯入前比對已安裝的驅動，由你決定覆寫或略過。

深色介面

兩個分頁：匯出驅動、匯入驅動。

自動要求系統管理員

執行檔內嵌 manifest，啟動時要求提升權限。

本工具直接操作 Windows 驅動程式存放區， 適合進階使用者與 IT 管理員，請謹慎使用。
