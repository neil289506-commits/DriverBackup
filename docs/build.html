自行建置

cargo build --release
.\target\release\driver_backup.exe

相依套件:eframe / egui 0.27、rfd、chrono、walkdir、winreg。建置時 build.rs 會用 winres 嵌入要求系統管理員的 manifest;release 設定為 LTO 並移除符號。介面字型使用 repo 內的 msjh.ttf(微軟正黑體)。

repo 預設分支為 V1.0,另有 V1.0-Noico 標籤。
